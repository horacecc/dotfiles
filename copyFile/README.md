## Installation
1. In your terminal, change to the directory that you want to store the files.
2. Clone the repo: `git clone ___`
3. `cd ___`
4. Create and activate the virtual environment: `pipenv shell`
5. Install pip to develop mode: `pipenv install -dev`
6. Copy `example.env`, Make your `.env`

## Running
* `pipenv run python manage.py makemigrations`
* `pipenv run python manage.py migrate`
* `pipenv run python manage.py createsuperuser`
* Run the command `pipenv run python manage.py runserver localhost:8000` in your ___ working directory to start the server.
