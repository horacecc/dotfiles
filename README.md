| Item | Directory |
| -------- | -------- |

| [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions) | `~/.zsh/zsh-autosuggestions` |

## Start ZSH

```bash=
cd ~
git clone https://github.com/yatimisi2018/.my-zsh.git
python3 ~/.my-zsh/start_zsh.py
```
